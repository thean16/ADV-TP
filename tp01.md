# Part 1 — Python Basic Concepts

## 1. Variable

A variable is used to store a value.

```python
student_name = "Student A"
age = 20
score = 85
```

Simple idea:

```text
Variable → stores data
```

---

## 2. Function

A function is a reusable block of code that performs a specific task.

```python
def add(a, b):
    return a + b


result = add(5, 3)
print(result)
```

Output:

```text
8
```

Simple idea:

```text
Function → reusable code that performs a task
```

---

## 3. Class

A class is a blueprint used to create objects.

```python
class Student:
    pass
```

We can create an object from the class:

```python
student1 = Student()
```

Simple idea:

```text
Class → blueprint
Object → instance created from the class
```

---

## 4. Method

A method is a function defined inside a class.

```python
class Student:
    def study(self):
        print("The student is studying.")


student1 = Student()
student1.study()
```

Simple idea:

```text
Method → function inside a class
```

---

## 5. Constant

A constant is a value that should normally remain unchanged.

```python
PI = 3.14159
MAX_SCORE = 100
```

Python usually uses uppercase names for constants.

```text
Constant → fixed value
```

---

## 6. Module

A module is a Python file containing reusable code.

Example:

```text
calculator.py
```

Inside `calculator.py`:

```python
def add(a, b):
    return a + b
```

Use it from another file:

```python
import calculator

print(calculator.add(5, 2))
```

Simple idea:

```text
Module → one Python file
```

---

## 7. Package

A package is a folder containing related Python modules.

Example:

```text
data_tools/
│
├── __init__.py
├── cleaning.py
├── analysis.py
└── visualization.py
```

Simple idea:

```text
Package → collection of related modules
```

---

# Basic Concept Summary

| Concept | Meaning |
|---|---|
| Variable | Stores data |

# Part 2 — Clean Code

Clean code means writing programs that are easy to understand, modify, debug, and maintain.

## Readability

Bad example:

```python
a = 10
b = 5
c = a * b
```

Better example:

```python
price = 10
quantity = 5
total_price = price * quantity
```

The second example is better because the variable names clearly explain their meaning.

---

## Maintainability

Instead of repeating code:

```python
total1 = 10 * 2
total2 = 20 * 3
```

Create a function:

```python
def calculate_total(price, quantity):
    return price * quantity


total1 = calculate_total(10, 2)
total2 = calculate_total(20, 3)
```

Now, if the calculation changes, we only need to modify one function.

# Part 3 — PEP 8

PEP 8 is the Python style guide.

It helps programmers write consistent and readable Python code.

Important rules:

| Item | Style |
|---|---|
| Variables | `snake_case` |
| Functions | `snake_case` |
| Classes | `PascalCase` |
| Constants | `UPPERCASE` |
| Indentation | 4 spaces |

Example:

```python
student_name = "Student A"
MAX_SCORE = 100


def calculate_average():
    pass


class StudentProfile:
    pass
```

# Part 4 — Exception Handling

Exception handling allows a program to manage errors safely.

Example:

```python
try:
    number = int(input("Enter a number: "))
    print(100 / number)

except ValueError:
    print("Please enter a valid integer.")

except ZeroDivisionError:
    print("The number cannot be zero.")
```

Important keywords:

```text
try
except
else
finally
raise
```

# Part 5 — Debugging

Debugging means finding and fixing problems in code.

A simple debugging process is:

```text
Read the error
      ↓
Find where it happened
      ↓
Understand the problem
      ↓
Check the values
      ↓
Fix the code
      ↓
Run again
```

Common Python errors include:

- `SyntaxError`
- `TypeError`
- `ValueError`
- `NameError`
- `IndexError`
- `KeyError`
- `FileNotFoundError`
